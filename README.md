> Single-page developer portfolio and application showcase designed for **Duales Studium Informatik (2027)** applications in Germany.

---

## 🌟 Features

* **Single-Page Architecture:** Smooth navigation across Hero, About Me, Education Timeline, Technical Skills, and GitHub Repositories.
* **Bi-Language Support:** Instant switching between German (`DE`) and English (`EN`) to accommodate technical reviewers and recruiters.
* **Custom Dark Theme:** Built using Ant Design (`ConfigProvider`) with a custom emerald green (`#10b981`) and deep charcoal minimal aesthetic.
* **Education Timeline:** Highlights academic progression from Odesa NVK №90 to Gymnasium Münsingen, Berufsschule, and Berufskolleg Reutlingen (BK2).
* **Focus on Software Engineering:** Emphasizes C# .NET, Clean Architecture principles, Object-Oriented Design (OOP), and web automation.

---

## 🛠️ Tech Stack

* **Frontend:** React 19, TypeScript, Ant Design 5
* **Build Tool:** Vite
* **Styling:** CSS3, Custom Ant Design Theme Config
* **Deployment:** Vercel
